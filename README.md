# Nombre del Proyecto
Taller GitFlow Práctica
## Descripción
En este proyecto se llevan a cabo prácticas sobre el manejo de git para estudiantes.
## Instalación
1. Ve al repositorio del profesor en github
2. Utiliza el acceso directo "Use this template" y crearás tu propio repositorio
3. Clona el repositorio en tu máquina local: git clone https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git
4. Completa las misiones
## Uso
Este proyecto puedes utilizarlo para probar comandos básicos de git. Por ejemplo: 
* Ver estado (rama): git status
* Cambiar a otra rama: git checkout nombreRama
* Crear una rama nueva: git checkout -b nombreRama
* Subir rama al repositorio remoto: git push -u origin rama

release/v1.0.0 - Cambios revisados y probados para enviar a main
hotfix/readme-typo - Correcciones en caliente
